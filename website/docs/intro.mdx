# Getting started

Skul applies a shared **bundle** — skills, commands, agents, instructions, MCP servers — to a project, in the layout each AI coding tool expects, and keeps it out of Git.

## Install

```bash
npm install --global @solaqua/skul
```

Needs Node.js 20+ and Git.

## Apply a bundle

```bash
skul add acme/ai-bundles react-expert
```

Skul clones `acme/ai-bundles` into `~/.skul/library/`, asks which tools to target, writes the files, and adds them to `.git/info/exclude`. Run `git status`: nothing changed.

Narrow it down when you want less:

```bash
skul add react-expert --agent codex                       # one tool
skul add react-expert --include skills/diagnose           # one item
skul add react-expert --ref v2                            # a branch, tag, or commit
```

## Keep going

```bash
skul status     # what is applied, and where
skul update     # pull newer bundle revisions
skul apply      # reproduce the setup in a fresh worktree
skul remove react-expert
```
